# 红警3修改器（RA3 Trainer）

给《命令与征服：红色警戒3》用的**单机**辅助工具。启动游戏后连接，在游戏里按 `Ins` 打开面板，
用小键盘直接开关各项功能 —— 不需要切出游戏，也不需要记复杂的操作。

> 仅用于单机与人机对战。请勿在联机对战中使用。

## 功能

| 分类 | 内容 |
| --- | --- |
| 资源 | 改钱、改电力、资源数值按档递增 |
| 建造 | 快速建造（一键开启）、生产上限相关辅助 |
| 战场 | 消散战争迷雾、复制选中的建筑/单位给自己、单位增援（含各阵营与 mod 单位） |
| 单位 | 增援单位列表按 mod / 阵营分类，自动读取游戏与 mod 自带的单位名字表 |
| 其它 | 心灵控制、威胁等级、矿点等（高风险项默认关闭，需要时在诊断页打开） |

- **开箱即用**：不需要安装 .NET 运行库，不需要配置。
- **认识你的 mod**：自动识别当前使用的 mod（如 Remix、日冕），并从 mod 自带的数据里读出单位中文名。
- **不联网**：程序只在本地读写游戏进程内存，不上传任何数据。

## 运行要求

- Windows 10 / 11（32 位、64 位均可）
- 与游戏**保持同一个权限级别**（都用普通用户启动；一个管理员一个普通用户会连不上）

## 快速开始

1. 下载 `红警3修改器.exe`（单文件，免安装）
2. 双击运行 → 在「01 启动」页点「浏览」选择游戏启动器（如 `ARModLauncher.exe` / `RA3.exe`）
3. 点「开启修改」→「连接游戏」；或直接点「一键启动并装载」
4. 游戏里按 `Ins` 打开面板：

```
Num8 / Num2  选行            Num5  执行
Num4 / Num6  调数值（先按 5 进入调节）   Num7 / Num9  换页
Num0 返回                    Ins  关闭面板
```

## 出问题怎么办

打开「04 诊断」页：连接状态、改动点、已启用功能一屏看完；点「打开日志」「导出问题记录」可拿到排查文件。
数据目录（设置、单位清单、日志、现场记录）：`%LocalAppData%\Ra3Trainer` —— 诊断页有「打开数据目录」按钮。

## 常见问题

- **杀毒软件报可疑**：本工具需要读写游戏进程内存，部分杀软会误报；程序不联网、无其它行为，添加信任即可。
- **面板按 Ins 不显示**：确认已「连接游戏」；诊断页有占槽排查指引。
- **连不上游戏**：检查两者权限级别是否一致，以及是否使用了与游戏位数匹配的版本（本程序为 32 位）。
